# 03. Feature Inventory

Roles (templates in `packages/reference-data/src/roles.ts`; access is by **permission key**, never by role name): Administrator (all 69 permissions), Accountant, Billing Operator, Warehouse Operator, Viewer/Auditor (read only). "Production-ready" means safe for real business use today; **no module is production-ready for real GST billing** because production billing is gated off (R-040, backup/restore gate, tax review) and several essential documents are missing (see `06`). Items marked Verified have automated tests that passed on 2026-10-29/2026-11-06 (`08_TEST_AND_QUALITY_REPORT.md`).

## C. Background processes

Only the managed PostgreSQL process and the local API child process (supervised by the Electron shell, with a parent-process watchdog), plus an idle-session expiry check inside the auth service. No cron, queue or sync worker.
